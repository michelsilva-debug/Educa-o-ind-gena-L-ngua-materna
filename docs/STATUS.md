# Status do projeto

## Consolidado — versão inicial

### Implementado
- Modelo inicial de comunidade e clãs.
- Papéis de governança.
- Permissões explícitas.
- Políticas de validação.
- Validação por clã.
- Proteções de autorização e publicação.
- Auditoria.
- Painel visual demonstrativo.

### Ainda não implementado
- Autenticação real.
- Persistência do painel via Supabase.
- Cadastro real de usuários/clãs.
- Conteúdo linguístico oficial.
- Alfabeto/famílias silábicas oficiais.
- Conteúdo cultural/tradicional oficial.
- IA em produção.
- Sincronização offline.

### Princípio de desenvolvimento

Nenhum desses itens deve ser preenchido por suposição técnica. O conteúdo cultural e linguístico deverá ser definido e validado pela comunidade.
