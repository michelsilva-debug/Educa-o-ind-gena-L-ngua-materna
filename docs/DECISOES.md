# Decisões de arquitetura

1. A governança comunitária é parte do modelo de dados e das regras de segurança.
2. O sistema não contém regras linguísticas ou culturais pré-definidas como verdade.
3. Conteúdo comunitário possui status, versão, origem, nível de acesso e validações.
4. Validação exige representante autorizado e vínculo com o clã correspondente.
5. Publicação pode ser bloqueada pelo banco quando a política comunitária exigir validação.
6. Papéis técnicos não recebem permissão de validação cultural automaticamente.
7. Toda validação gera evento de auditoria.
8. A política de validação é configurável pela comunidade.
9. O modelo deve suportar funcionamento offline futuramente sem perder a trilha de auditoria após sincronização.
10. Qualquer modelo de IA deverá consumir somente conteúdo autorizado para o contexto solicitado.
